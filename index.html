Recursos

  • KBase — www.kbase.us

    Plataforma del Departamento de Energía de EE.UU. para analizar genomas, metagenomas y redes metabólicas en la nube, mediante "Narratives" reproducibles y sin necesidad de programar.

  • Galaxy — usegalaxy.org

    Plataforma web abierta y gratuita para análisis bioinformáticos (secuenciación, RNA-seq, alineamientos, etc.) con herramientas gráficas y flujos de trabajo reproducibles.

  • Curso básico NLHPC

    Material del curso introductorio del Laboratorio Nacional de Computación de Alto Rendimiento de Chile: uso de Linux, conexión al clúster y envío de trabajos con Slurm.

  • Instalar WSL — Microsoft Learn

    Guía oficial para instalar el Subsistema de Windows para Linux (WSL), que permite usar Ubuntu y herramientas de línea de comandos de Linux directamente en Windows.
